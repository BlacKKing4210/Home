# PD-004 动物居民小镇品质扩面决定

**状态：** `APPROVED_FOR_F004_RESIDENT_2_DESIGN`
**日期：** 2026-07-27
**制作人：** Codex `/root`
**来源：** 用户要求确认五项动物居民小镇目标的真实完成度，并继续迭代提高品质与完成度。

## 决定

F004-RESIDENT.1 继续作为已接受的高品质代表性基线，但不再把“一名居民、一条谷物链”解释为五项产品目标整体完成。下一优先功能建立为：

> `F004-RESIDENT.2：乳品邻里与居民日常`

本功能先于 F-005 铁路货运推进。原因不是降低铁路优先级，而是用户要求先解决当前主页面最直接的空间秩序、动物居民数量、建筑操作归属和生活感不足。F-005 仍保持路线图依赖，不被删除或冒充完成。

## 体验判断

单一记忆点保持不变：

> 动物不是按钮或加成，而是玩家看得见、会走路、会生活、会把小镇运转起来的居民。

本轮新增的玩家可见证明是：

> 玩家在清晰网格上放下第二栋住房、道路、乳畜牧场和乳品工坊，邀请熊居民入住并派岗；熊居民沿路完成照料、挤奶、搬运和加工，把乳品装上到访车辆，随后回到生活状态。

## 产品减法

- 不新增重复货币。
- 不把乳品链做成新的常驻菜单。
- 不要求玩家逐批点击“开始、完成、收取”。
- 不做 RTS 式逐步移动命令。
- 不加入复杂社交、对话树、恋爱、家庭或装饰收藏。
- 不在本轮批量引入所有历史 F003 建筑。

## 正式空间目录

| 对象 | 占地 | 角色 |
|---|---:|---|
| 道路 / 生活点 | `1×1` | 路网、入口、排队与短时生活 |
| 第二居民住房 | `2×2` | 1 名居民住房与生活根 |
| 乳畜牧场 | `3×3` | 牧场动物、喂养与挤奶作业点 |
| 乳品工坊 | `2×2` | 将牛奶加工为订单乳品 |
| 装卸场 | 复用 `3×2` | 第二辆车辆的世界内装载点 |

空间规则不迁就现有 PNG。正式资产必须按上述占地、入口、作业点、遮挡包络和 45° 可读性重新设计。

## 居民与牧场动物边界

- 熊是可邀请、可入住、可派遣、有生活状态的居民。
- 奶牛是乳畜牧场中的生产动物，不占居民住房位，也不能被派遣到建筑。
- 熊居民负责准备饲料、照料奶牛、挤奶、搬运牛奶和操作乳品工坊。
- 玩家只做建造、邀请、派遣、道路调整和订单承诺。
