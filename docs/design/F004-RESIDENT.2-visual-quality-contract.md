# CityOfAnimals F004-RESIDENT.2 视觉质量合同

**合同 ID：** `COA-VQ-F004-RESIDENT-002`
**版本：** V1.0 / 2026-07-27
**范围：** 第二住房、乳品牧场、乳品工坊、第二居民、第二订单车、真实占地放置与双居民日常
**目标：** 720×1280 竖屏、45° 等距 2D 卡通
**状态：** `VISUAL_SCALEOUT_CONTRACT_APPROVED / ASSET_SET_PENDING / RUNTIME_NOT_AUTHORIZED`
**继承：** F004-RESIDENT.1 已批准方向与运行分层；本合同只定义新增扩面。

## 1. 一句话视觉方向

**像一本会自己运转的温暖动物小镇绘本：清楚的菱形底座建立空间秩序，奶白、青草与陶红组成乳品邻里，熊与兔子的通勤、劳动和回家让建筑从模型变成被居民使用的生活场所。**

## 2. 玩家记忆画面

玩家在清楚的 `3×3` 牧场底座旁看见熊居民照料奶牛、提起奶罐，沿自己铺的道路走进 `2×2` 乳品工坊，再抱着乳品箱走向第二辆订单车；车厢装满后鸣笛驶离，熊回到新家门前，兔子也从谷物岗位回家。

## 3. 视觉原则

1. **占地先于建筑装饰。** 每个对象的底座、入口和道路连接在 50% 缩放下仍可读。
2. **功能部件形成剪影。** 牧场靠围栏、奶牛位和挤奶棚；乳品工坊靠奶罐、搅拌器和灌装台；不靠文字标签。
3. **居民行为代替 UI。** 用走路、工具、货物、工作点响应和车辆货箱表达因果。
4. **同一小镇，不是贴图拼盘。** F004.2 新资产必须继承 F004.1 的轮廓厚度、光向、地面频率和色彩职责。
5. **生活密度有节制。** 居民、门灯、奶罐、围栏门、短烟气和车辆扬尘创造活力；状态图标和粒子均受预算。
6. **正式资产才进主地图。** 候选、临时、emoji、字母块、灰框和 `NOT_RUNTIME` 不得进入玩家可见验收路径。
7. **原创反复制。** 只学习慢节奏、居民存在感、生产链与世界交付的抽象方法；不复制商业角色、建筑、布局、UI、数值、文案、色板或品牌。

## 4. 形状与占地职责

| 对象 | 占地 | 形状职责 |
|---|---:|---|
| 道路/生活点 | `1×1` | 软菱形土路，四边连接明确；长椅/路灯位于边缘，不遮通行中心 |
| 第二住房 | `2×2` | 低而宽的居住剪影，正面门与门灯，底座四边完整可见 |
| 乳畜牧场 | `3×3` | 最大轮廓来自围栏与挤奶棚；奶牛位、饲料点、挤奶点彼此可分 |
| 乳品工坊 | `2×2` | 紧凑方形工坊，奶罐烟囱/搅拌器形成独特顶线，入口与收料台可读 |
| 熊居民 | 动态 | 圆厚体型、短耳与围裙/工具形成乳品岗位剪影，64–96 px 仍可识别 |
| 奶牛 | 牧场内 | 四足、低重心、明显斑块，但保持 CityOfAnimals 自己的比例与脸型 |
| 乳品车 | 动态 | 奶白货箱 + 青绿功能件；车头方向和一格货箱槽位清楚 |

建筑图片透明包络可以有屋檐和围栏装饰，但逻辑底座永远按目录绘制并承担触控与冲突反馈。

## 5. 色彩、材质与光影

| 角色 | 建议范围 | 用途 |
|---|---|---|
| 地面绿 | 低饱和黄绿色 | 大面积背景 |
| 道路土黄 | 温暖浅赭 | 路网与入口 |
| 乳品奶白 | 暖白/奶油 | 工坊、奶罐、车辆货箱 |
| 生活陶红 | 珊瑚陶红 | 住房屋顶与生活焦点 |
| 生产青绿 | 青绿 | 正常工作、可派遣、路径 |
| 完成暖金 | 暖金 | 建造确认、货箱完成 |
| 阻塞珊瑚 | 珊瑚红 | 冲突、断路、失败 |
| 深墨轮廓 | 深青灰/深棕 | 世界边界、文字、状态外轮廓 |

- 光源统一来自左上方；接触阴影短、软、方向一致。
- 草地为低频颗粒；道路为压实土与少量碎石；牧场为草/泥复合地面；乳品工坊用木、浅石和陶瓦。
- 奶白必须与 HUD 承载面区分；复杂背景上的文本只能放在独立面板。
- 合法/非法放置不只改颜色：合法为完整双线底座，非法叠加斜纹和冲突格。

## 8. 动效职责

| 行为 | 常规表现 | reduced-motion |
|---|---|---|
| 放置预览 | 候选轻跟随、合法边界呼吸一次 | 静态边界切换 |
| 建造完成 | 轻尘、短回弹、门灯点亮 | 直接显现 + 轮廓确认 |
| 熊走路 | 轻微上下步态、方向倾斜、围裙/奶罐滞后 | 仅位置和朝向 |
| 照料 | 俯身、递饲料、奶牛抬头 | 姿态切换 |
| 挤奶 | 侧身、短节奏手部/奶罐响应 | 静态挤奶姿态 + 进度 |
| 搬运 | 奶罐/乳品箱作为独立 visual child 跟随 | 保留货物位移 |
| 加工 | 熊操作，工坊搅拌器/短蒸汽同步 | 静态工作姿态 + 工坊状态 |
| 装载 | 乳品箱进入货箱，槽位填满 | 分段状态替换 |
| 车辆离场 | 启动、鸣笛、短扬尘、平稳驶离 | 无镜头冲击，平滑离开 |
| 生活 | 轻看向、坐下/回家、门灯响应 | 静态停留 |

程序化动作沿用项目批准的 `zhanchengdashi` 方法论，只作用于视觉子节点；可中断、可重置、离树清理，禁止无限 Tween。

## 9. 声音职责

- 放置：柔和落地与确认音；
- 熊脚步：低频、随道路材质、限制并发；
- 照料/挤奶：短循环，镜头外衰减；
- 乳品工坊：低噪声搅拌/灌装，不压过车辆完成声；
- 货物入箱：一次清楚的木箱/奶瓶落位声；
- 车辆：远处进入、停车、完成鸣笛、离场四层；
- 回家/生活：门铃或轻生活声，低优先级；
- 阻塞：一次短提示，不持续报警。

视觉必须在静音下独立可读；无合规音源时只使用批准的程序化短音。

## 11. 安全区、触控与可读性

- 720×1280 竖屏；响应式等比缩放并居中。
- 顶部与底部安全区由运行设备传入。
- 最小触控区 52×52 px；相邻控件间隔至少 8 px。
- 放置对象与手指保持上方偏移预览。
- 建筑入口、道路连接、候选占地在无文字、灰度和 50% 缩放下仍可读。
- zh-CN / en 验证标题、状态、空态、错误和数值不溢出。
- 关键状态使用形状/纹理 + 轮廓/图标两种线索。

## 12. 性能预算

- Windows GL Compatibility，720×1280：目标 60 FPS，验收底线稳定 30 FPS。
- 同屏居民预算 12 名；本切片 2 名。
- 同屏牧场动物预算 6；本切片 1 头奶牛。
- 可见车辆 1；另一订单车必须完成释放后再生成。
- 活动程序化反馈最多 8 组；短粒子自动释放。
- 路网只在占地变化时增量更新；禁止每帧全图寻路。
- 居民离屏后降低视觉更新频率；逻辑任务使用低频调度。
- 资产按 720×1280 显示需求控制纹理尺寸，不引入无效 4K 单图。
- 无 ObjectDB、音频节点、Tween 或临时导航节点泄漏。
