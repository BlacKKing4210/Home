# F004-RESIDENT.2 主页面 UI/UX 优先级

**版本：** V1.0 / 2026-07-27
**目标画布：** 720×1280 竖屏
**输入：** 触控为主；鼠标用于桌面调试
**默认语言：** `zh-CN`；设置中可切换并持久化 `en`
**状态：** `UI_UX_SCALEOUT_APPROVED / PENPOT_SCALEOUT_READBACK_VERIFIED`
**适用：** 真实占地放置、第二住房邀请、乳品派遣、第二订单车与双居民日常

## 1. 单一主要决定

主地图任何时刻只要求玩家回答一个问题：

> **我要把哪一个对象放在哪里，或把哪一名居民安排到哪个岗位？**

挤奶、加工、搬运和装车是居民的世界行为，不进入常驻 CTA。

## 2. 信息优先级

| 层级 | 必须读到 | 表达方式 | 文字预算 |
|---|---|---|---|
| P0 | 当前候选占地是否合法；熊正在去哪/做什么；第一阻塞 | 占地边界、冲突格、入口、路径、居民姿态、一个阻塞图形 | 0–1 个短词 |
| P1 | 住房空位、乳品岗位、车辆等待与货箱进度 | 门牌、岗位徽记、车辆货箱、稳定 HUD 数值槽 | 图标 + 数值 |
| P2 | 建造成本、派遣关系、输入/输出、预计阶段 | 底部情境层 | 两行以内 |
| P3 | 详细配方、居民履历、设置与辅助选项 | 二级详情/设置 | 可滚动，不占世界常态 |

## 3. 页面与状态

### 3.1 `12_Expansion_Placement_720x1280`

主要决定：确认第二住房或乳品建筑的合法落位。

- 世界保留可见，镜头聚焦候选邻域。
- 候选底座逐格显示；入口和最近道路连接清楚。
- 底部只保留“确认建造”一个主 CTA，取消为次级动作。
- 成本与占地使用图标/数值；不展示长功能说明。
- 未连通允许确认，但入口使用琥珀警告并显示“未连路”短原因。

### 3.2 `13_Placement_Invalid_720x1280`

主要决定：移动候选对象以消除一个冲突。

- 冲突格使用珊瑚斜纹 + 深轮廓，不只靠红色。
- 只显示第一原因：重叠、越界、入口被占、保留车道或资源不足。
- 主 CTA 保留但禁用；候选对象可以拖动或按格移动。
- 不弹模态，不清空草稿。

### 3.3 `14_Second_Home_Invite_720x1280`

主要决定：是否邀请熊入住当前空住房。

- 世界中住房门牌显示空位，点按后出现底部情境层。
- 熊作为到访者用正式立绘/世界角色呈现；不使用卡牌堆。
- 主 CTA：“邀请入住”；次级：“稍后”。
- 成本不足时保留 CTA 位置，显示缺口，不重排页面。
- 成功后面板收起，镜头回到世界，熊从小镇入口出现并沿路到家。

### 3.4 `15_Dairy_Assignment_720x1280`

主要决定：把熊派遣到乳品岗位。

- 选中乳品牧场后，高亮牧场入口、工坊入口和完整通勤路径。
- 岗位卡只显示熊头像、住房、当前状态与工作链图形。
- 主 CTA：“派遣到乳品岗位”；已有岗位时显示“调整岗位”。
- 奶牛不出现在居民候选列表中。
- 无路、住房未入住或岗位占用时禁用，并只显示第一条件缺口。

### 3.5 `16_Dairy_Work_And_Truck_720x1280`

主要决定：若无阻塞，玩家无需操作；观察因果。

- 熊姿态依次表达照料、挤奶、搬运、加工和装车。
- 奶罐/乳品箱作为独立世界物体随熊移动。
- 车辆货箱从 `0/1` 到 `1/1`，满载后自动鸣笛离场。
- 常态不出现“挤奶、开始加工、收取、装车”按钮。
- 点按车辆只展开需求、装载和等待状态；一个主行动最多是“定位缺口”。

### 3.6 `17_Two_Residents_Leisure_720x1280`

主要决定：无；这是小镇活着的结果画面。

- 兔子回住房门前，熊到生活点或回家。
- 居民不叠位、不阻塞道路、不播放高强度循环特效。
- 世界保持生产状态低噪声，HUD 仅显示稳定资源。
- 生活动作不引入额外数值或奖励按钮。

## 4. 入口与出口

| 场景 | 入口 | 主行动 | 退出 |
|---|---|---|---|
| 扩建 | 空地/建造入口 | 确认建造 | 确认、取消或保存草稿 |
| 非法放置 | 候选对象发生冲突 | 移动候选并重新验证 | 合法后确认/取消 |
| 邀请 | 空住房门牌/到访熊 | 邀请入住 | 成功/稍后 |
| 派遣 | 熊或乳品建筑岗位 | 派遣/改派 | 确认后回地图 |
| 乳品运行 | 世界内熊/牧场/工坊/车辆 | 无；阻塞时“定位缺口” | 自动继续/点空白收起 |
| 日常 | 工作段结束 | 无 | 下一任务自动开始 |

| 状态 | 放置 | 住房/邀请 | 乳品岗位 | 车辆 | 恢复 |
|---|---|---|---|---|---|
| Default | 不显示全图网格 | 空位门牌低噪声 | 建筑空闲/工作 | 未出现或远处 | 点选对象 |
| Selected | 候选邻域与占地清楚 | 住房轮廓 | 路径与入口 | 货箱与需求 | 点空白收起 |
| Loading | 候选保持原位 | 稳定骨架 | 当前居民姿态保持 | 车辆保持位置 | 数据到达 |
| Empty | 无可建对象说明入口 | 无空位 | 无可派居民 | 暂无车辆 | 满足条件 |
| Disabled | 冲突/资源不足 | 缺住房/资源 | 缺路/入住/岗位 | 不可承诺 | 条件满足 |
| Failure | 不扣费、不落位 | 不重复扣费 | 保留旧岗位 | 不发奖 | 重试 |

## 6. 明确移除

- 常驻“挤奶、开始、加工、完成、收取、装车”按钮。
- 常驻居民列表、订单列表或生产队列。
- 整屏调试网格、坐标文字和占地数字。
- 多个同等权重 CTA。
- 以颜色作为唯一合法/非法线索。
- emoji、字母块、灰框、临时图、候选图和 `NOT_RUNTIME` 水印泄漏。
- 复制参考商业游戏的页面布局、角色卡、图标或订单板。

## 7. HUD 与底部情境层

- 顶部 HUD 不超过 104 px（不含安全区）：小镇级别、金币、仓储、设置。
- 世界区占可用纵向空间至少 80%。
- 底部情境层默认收起；展开 280–420 px。
- 面板不能遮住当前对象的主要轮廓、入口和居民。
- 一个主 CTA；次级动作不超过 2 个。
- 动态数值使用稳定宽度槽，中文和英文切换不挤动图标。

## 8. 触控、文本与可访问性

- 最小逻辑触控区 52×52 px，相邻操作至少 8 px。
- 放置拖拽过程保持手指上方偏移预览，避免候选被手指遮住。
- 中文短标签 2–6 字；英文预留 1.35 倍宽度。
- 关键状态至少使用形状/纹理 + 轮廓/图标两种线索。
- 文字与承载面达到可读对比，不直接落在复杂草地上。
- reduced-motion 关闭弹跳、粒子弧线、循环呼吸和镜头冲击；保留位置、姿态、路径与数值。
- 声音提示同时有视觉等价，不依赖听觉完成操作。
