**输入：** 触控为主；鼠标用于桌面调试  
**默认语言：** `zh-CN`；设置中可切换并持久化 `en`

**Penpot：** `EDITABLE_SOURCE_READBACK_VERIFIED / LOCAL_EXPORT_RECONCILED`；云端下载错误已记录，未冒充云端导出成功

## 1. 单一主要决定

玩家每次回到主地图只需要回答：

> **我接下来要改善哪一段小镇运转：建造/连路、邀请居民、安排岗位，还是处理一个阻塞？**

主地图不再要求玩家持续寻找“可点击的生产按钮”。

## 2. 信息优先级

| 层级 | 玩家必须读到 | 主要表达 | 常态文字 |
|---|---|---|---|
| P0 | 居民正在去哪、在做什么、哪里阻塞；当前选中对象 | 居民剪影与动作、道路路径、建筑作业点、阻塞图形、车辆装载 | 不超过一个短状态词 |
| P1 | 住房空位、岗位空位、订单车等待、仓储余量 | 世界内门牌/岗位牌、车辆货箱、稳定 HUD 数值槽 | 图标 + 数值 |
| P2 | 建造成本、工作输入/产出、预计时长、优先级 | 选中对象后出现的底部情境层 | 两行以内 |
| P3 | 详细履历、完整配方、统计、设置 | 二级详情页或设置 | 可滚动，但不占常态主地图 |

## 3. 明确移除

- 常驻“播种、收获、喂养、开始、收取”按钮。
- 常驻订单卡列表与大面积说明文字。
- 每栋建筑同时显示名称、计时、缺料、完成等多个气泡。
- 以字母块、emoji、未批准灰框或临时图标代表玩家可见建筑/居民/车辆。
- 多个同等强度 CTA。
- 仅靠颜色区分可用、阻塞、锁定或完成。

## 4. 主地图布局

### 顶部安全区

- 左：小镇等级/名称，只在状态变化或点按时展开。
- 中：金币、通用仓储占用，使用稳定数值槽。
- 右：设置和“待处理数”入口；不常驻显示完整任务列表。
- 顶部总高度目标不超过 104 px（不含设备安全区）。

### 世界区

- 至少 80% 的可用纵向空间留给地图。
- 建筑、道路、居民和车辆直接承担信息表达。
- 选中居民后：显示其当前路径、岗位和一个主行动（派遣/改派/回家）。
- 选中建筑后：显示入口、作业点、岗位占用、输入/输出和一个主行动（分配居民/调整优先级）。
- 选中车辆后：显示需求、已装载、缺口和一个主行动（承诺/谢绝/定位来源）。

### 底部情境层

- 默认收起，只保留 56–64 px 的情境把手或完全隐藏。
- 展开高度目标 280–420 px；不得遮住当前选中建筑的主要轮廓、入口和居民。
- 只显示当前对象，不做全局功能导航栏。
- 主 CTA 一个；次要动作以图标/短标签呈现。

## 5. 入口与出口

| 场景 | 入口 | 主行动 | 退出 |
|---|---|---|---|
| 建造 | 点击空地或建造入口 | 放置并确认 | 取消/确认后回地图 |
| 邀请 | 点击住房空位或到访居民 | 邀请入住 | 完成/稍后 |
| 派遣 | 点击居民或建筑岗位 | 分配/改派 | 确认后回地图 |
| 道路 | 建造模式选择道路 | 连续铺设 | 确认/取消 |
| 车辆订单 | 点击到站车辆 | 承诺/谢绝/定位缺口 | 收起回地图 |
| 阻塞处理 | 点击世界内阻塞标记 | 定位并解决唯一阻塞 | 条件恢复后自动收起 |

## 6. 状态规范

| 状态 | 世界内表现 | 情境层 | 恢复 |
|---|---|---|---|
| Default | 居民按计划生活/工作，建筑保持低噪声 | 收起 | 点选对象 |
| Selected | 轮廓、入口和相关道路高亮 | 对象摘要 + 单一 CTA | 点空白/关闭 |
| Loading | 世界保持可见，目标对象低幅呼吸 | 稳定骨架，不跳布局 | 数据到达 |
| Empty | 住房/岗位空位用清晰图形表达 | “邀请居民”或“分配居民” | 完成对应动作 |
| Disabled | 行动保留但降级，显示缺少的条件图标 | 不可用原因一行 | 条件满足 |
| Failure | 世界对象保持原状态，短促警示 | 原因 + 恢复动作 | 重试/修路/腾仓 |
| Success | 居民或车辆完成动作，世界产生因果反馈 | 短确认，不弹强制模态 | 自动回地图 |
| Blocked | 居民停在安全点，建筑/道路显示阻塞标记 | 只显示第一阻塞原因 | 条件满足后恢复 |
| Interrupted | 保持保存前选择与任务快照 | 返回时总结一次变化 | 确认后继续 |
| Reduced motion | 无位移弹跳/粒子循环 | 轮廓、静态姿态、数值变化 | 持久化偏好 |

## 7. 状态气泡预算

- 每栋建筑常态最多 1 个状态标记。
- 同屏最高突出 4 个 P0/P1 标记；其余只保留低对比世界状态。
- 优先级：`路径断开 > 仓储/装载阻塞 > 缺关键输入 > 无居民 > 车辆等待 > 工作中 > 空闲`。
- 居民头顶常态不显示文字；只在选中或阻塞时出现图形提示。

## 8. 触控、文本与可访问性

- 最小逻辑触控区：52×52 px；相邻操作至少 8 px。
- 建筑视觉小于触控区时，触控区沿地面占地扩展，不覆盖邻居。
- 动态数值使用稳定槽，1–3 位变化不挤动图标。
- 中文短标签优先 2–6 字；英文按 1.35 倍宽度预留。
- 关键状态至少使用形状/图标 + 轮廓/材质两种线索。
- 文字与承载面达到可读对比；不把浅色文字直接放在复杂草地上。
- reduced-motion 关闭居民弹跳、循环呼吸、粒子弧线和镜头冲击，保留姿态、轮廓、路径与数值反馈。
