## 1. 玩家可见目标

玩家点击一块成熟田地后，必须在同一视野内看懂“作物离开田地、进入粮仓、田块恢复空闲”的完整因果，而不是只看到库存数字变化。

## 2. 代表性切片

- 场景：720 x 1280 主地图起始农田区。
- 入口：一块成熟作物田地处于可收获状态。
- 动作：玩家点击成熟田地。
- 成功：田块反馈按压与丰收光环，作物粒子沿弧线飞向粮仓容量区，显示本次产量，田块恢复空闲。
- 失败：粮仓容量不足时不播放成功飞行动效；成熟作物保留，田块和容量区给出阻塞脉冲。
- 减少动态效果：关闭抛物线移动与连续脉冲，改用短暂静态起点/终点高亮和产量文字。
- 中断/恢复：切后台、节点离树或再次快速收获不会移动逻辑节点，不改变碰撞、焦点、触控区或经济结算。
