## 1. 术语与边界

| 术语 | 定义 |
|---|---|
| 逻辑格 | 所有占地和寻路共同使用的整数网格单元。等距画面中显示为菱形，但逻辑上是直角网格。 |
| `1×1` | 一块最小田地的边长和面积单位；所有道路与建筑占地必须是整数格。 |
| 占地 | 建筑/田地/道路对逻辑格的排他占用矩形，不由图片透明边界决定。 |
| 入口 | 建筑边界外、必须与道路相邻的居民导航目标。 |
| 作业点 | 居民执行动作的逻辑位置；可位于建筑边界内的视觉偏移，但导航落点必须明确且可达。 |
| 装卸点 | 居民把货物交给车辆或存储的道路侧作业点。 |
| 居民 | 有住房、身份、日程、岗位、位置与任务状态的动物角色。 |
| 岗位 | 建筑提供的长期工作关系，不是一次性的生产按钮。 |
| 工作任务 | 居民在岗位中自动领取的原子工作：前往、排队、作业、搬运、存放。 |
| 订单车 | 在世界道路上到达、等待、装载并离场的订单实体。 |
| 低频操作 | 玩家进行建造、邀请、派遣、优先级和路线调整，而不逐批启动/收取。 |

### 1.1 功能边界

本版本定义：

- 统一逻辑网格与占地目录；
- 放置合法性、道路连接和居民寻路；
- 住房、邀请、入住、岗位、通勤、作业、搬运、生活；
- 一辆世界内订单车的完整生命周期；
- 主地图 UI/UX 与正式视觉质量合同；
- 代表性闭环的工程合同和 QA。

本版本不实现：

- 多居民社交关系、恋爱、家庭或复杂剧情；
- 多班次劳动法、工资、税收或劳动力市场；
- 在线好友、合作社、拍卖行或玩家交易；
- 铁路、飞机、船舶等后续大订单渠道；
- 付费加速、广告、抽卡或商业化；
- 批量资产生产和 Godot 运行时实装。

## 2. 设计目的与玩家感受

### 2.1 单一记忆点

**动物不是按钮或加成，而是玩家看得见、会走路、会生活、会把小镇运转起来的居民。**

### 2.2 玩家感受

玩家不是站在农场流水线旁反复按按钮，而是在规划一个有秩序、有人情味、会自行运转的小镇：

- 建一栋住房，是因为想让一位居民留下；
- 铺一段道路，是为了让居民真的走得到岗位；
- 建一块田或工坊，是在改变全镇的供给能力；
- 调整派遣，是在解决现实可见的拥堵或缺口；
- 完成订单，是看见居民把货装上车并送出小镇。

### 2.3 主要目标

1. 把频繁手动生产操作减少为低频规划。
2. 让动物居民成为所有建筑日常操作的执行者。
3. 让空间占地、道路、入口和工作点形成一致规则。
4. 把订单从裸面板包装为世界内车辆事件。
5. 让住房—邀请—生活—工作—交付构成可持续增长闭环。
6. 让主页面通过正式原创资产、动作和空间状态传达，不依赖长文字。

### 2.4 可观察规则

1. 没有居民的生产建筑不会自行工作。
2. 没有道路连到入口，居民不能到达建筑，建筑明确显示缺路。
3. 玩家派遣居民后，不需要逐批点击启动或收取；居民在条件满足时自动工作。
4. 居民会从当前位置或住房沿道路到岗位，完成后搬运产出并进入生活/下一任务。
5. 仓储、输入、岗位或装卸点阻塞时，任务保持，不吞物品、不重复结算。
6. 订单车真实到达、等待、显示货箱、被装载并离场。
7. 玩家建设住房并邀请居民，居民才成为小镇人口。
8. 同屏状态气泡受预算限制；世界动作优先于文字。
9. 所有主页面玩家可见资源为正式或已批准资源；占位只可 dev-only。
10. 切后台/退出后恢复到可解释状态，不让居民、货物或车辆无因瞬移。

## 3. 产品重基线与核心循环

### 3.1 核心循环

`观察小镇 → 发现容量/路线/岗位缺口 → 建造或调整 → 邀请/派遣居民 → 居民自主生活与工作 → 货物进入存储或车辆 → 订单车离场 → 获得建设资源 → 扩展住房、道路与生产网络`

### 3.2 三层节奏

| 时间尺度 | 玩家行为 | 世界行为 | 目标 |
|---|---|---|---|
| 10–30 秒 | 观察、点选居民/建筑/车辆、处理单个阻塞 | 居民走路、到达、开始作业 | 看懂因果 |
| 1–5 分钟 | 建造一处、派遣一人、调整一条路或承诺一单 | 多个工作任务顺序进行、货物搬运、车辆装载 | 低频规划 |
| 10–30 分钟 | 邀请新居民、扩建住房、增加生产能力 | 小镇形成新的生活/工作流量 | 可见成长 |
| 小时/天 | 区域扩张、岗位组合、居民收藏与长期目标 | 离线有限推进并返场总结 | 长期经营 |

### 3.3 操作频率目标

- 代表性闭环三分钟内，除镜头移动外不超过 8 次有意义点击。
- 一名居民分配到岗位后，完成一个常规生产批次不要求额外“开始/收取”点击。
- 主地图在条件满足时至少可连续 60 秒自行演化并保持可读。
- 任何阻塞最多通过“世界标记 → 点选 → 一条原因 → 一项恢复动作”完成定位。

### 3.4 减法

- 删除常态逐格播种、逐格收获、逐栏喂养、逐机开工和逐个成品收取。
- 删除日常循环中的多个常驻生产 CTA。
- 不新增重复货币、体力、工人券或订单票。
- 不用分区面板替代空间规划。
- 不以更多列表、教程文字和感叹号制造深度。

## 4. 代表性闭环

切片：`F004-RESIDENT-SLICE.1`

### 4.1 内容

- 1 栋 `2×2` 小型住房；
- 1 名动物居民；
- 从住房到岗位的道路；
- 1 块 `1×1` 田地或 1 个 `2×2` 代表工作建筑；
- 1 个道路侧装卸点；
- 1 辆订单车；
- 1 个只需单种产出的订单；
- 1 次奖励用于下一处建设。

### 4.2 玩家 UE

1. 玩家进入地图，看到一栋待建住房位置、道路起点、代表岗位和远处订单车入口。
2. 玩家选择住房并在合法 `2×2` 区域放置；入口必须邻接道路。
3. 建造完成后，住房显示一个空住户位，不弹长教程。
4. 到访动物出现在道路入口；玩家点住房或到访动物，确认邀请。
5. 动物沿道路走入住房，门口完成入住反馈。
6. 玩家点岗位，选择该居民并确认派遣。
7. 居民从住房出门，沿道路到岗位；无路时停在安全位置并提示缺路。
8. 到达后居民自动执行工作；田地/建筑与角色动作同步。
9. 产出生成后，居民把货物搬向装卸点。
10. 订单车到达并等待；货物进入货箱，装载状态在世界中可见。
11. 满载后车辆鸣笛离场；奖励进入稳定 HUD 槽。
12. 玩家获得足够资源规划下一栋住房或生产设施。

### 4.3 失败/恢复

- 住房不合法：保持预览，不扣资源，明确占用/越界/无入口。
- 无路：居民不穿越地形，任务保留，点阻塞定位断点。
- 缺输入：居民不出发或在岗位安全等待，不重复扣料。
- 岗位占用：任务排队或改派，居民不会叠在同一作业点。
- 仓储/装卸满：产物保留在输出位，居民进入阻塞，不丢失。
- 车辆离场中断：保存订单 ID、货物、阶段与位置快照，恢复后不重复奖励。

## 5. 统一空间系统

### 5.1 推导原则

空间规则不迁就现有 PNG 的透明边界。先从玩家理解和居民活动所需的“活动包络”推导：

1. 最小可生产单元必须是田地，所以田地定义 `1×1`。
2. 道路必须能以同一单位逐格连接，所以道路段定义 `1×1`。
3. 建筑占地由“主体 + 出入口 + 可读边界”决定，并用整数格登记。
4. 入口、作业点和装卸点是导航合同，不可只画在贴图上。
5. 美术必须适配批准占地；若现有资源无法适配，才进入重做列表。

### 5.2 逻辑网格

- 坐标：`grid_x, grid_y`，整数。
- 邻接：仅 `N/E/S/W` 四向连接；画面是 45°，逻辑不使用对角捷径。
- 渲染：每格投影为同尺寸菱形；`cell_width_px` / `cell_height_px` 在 Penpot style frame 通过后配置。
- 原点：世界地图有唯一逻辑原点与投影转换。
- Y-sort：以实体脚点/占地前缘计算，不以图片顶部计算。
- 地形：首切片仅 `buildable` 与 `blocked`；水、坡地等后续按相同格扩展。

### 5.3 占地目录 V0.9

| 类别 | 逻辑占地 | 入口/作业要求 | 首切片 |
|---|---:|---|---|
| 单格田地 | `1×1` | 1 个道路侧作业点；相邻田地可合并视觉边界 | 是 |
| 道路段 | `1×1` | 与四邻道路形成直、弯、丁、十、端点形态 | 是 |
| 小型住房 | `2×2` | 1 个居民入口；1–2 个住户位 | 是 |
| 小型工坊/公共设施 | `2×2` | 1 个员工入口、1 个作业点、1 个输出点 | 二选一 |
| 中型工坊 | `3×2` 或旋转 `2×3` | 员工入口、输入/输出点分离；1–2 岗位 | 否 |
| 动物照料建筑 | `3×3` | 员工入口、照料点、动物活动区 | 否 |
| 小型仓储 | `2×2` | 搬入/搬出点，可共用道路侧入口 | 否 |
| 订单装卸场 | `3×2` | 1 个居民装卸点 + 1 条道路侧车辆泊位 | 是 |
| 大型地标/交通站 | `4×4` 起 | 多入口、多阶段作业点；必须单独评审 | 否 |

此目录是制作人的推荐 V0.9。获得用户批准前，不批量重做建筑。

### 5.4 占地与视觉边界

- 占地矩形是唯一碰撞/放置权威。
- 屋檐、树冠、烟囱可有限越过占地的上方/后方，但不得遮住相邻入口或让触控归属不清。
- 建筑触控区以占地投影为基础；透明像素不产生额外占用。
- 作物、货物和居民视觉可越过格内中心，但逻辑脚点必须在自己的导航/作业位置。
- 旋转只允许 0°/90° 逻辑旋转；等距画面中的朝向由资源变体表达。

### 5.5 道路连接

- 每个道路格维护四向连接位掩码。
- 新路段放置后，只更新自己和四邻视觉。
- 建筑入口相邻格必须是道路，且从该道路格可到达至少一个“生活网络根”。
- 生活网络根首切片为住房入口和订单装卸场；后续可加入广场/交通站。
- 道路删除前预演：若会切断正在执行或已排定的住房—岗位、岗位—存储、存储—装卸路线，则阻止删除或要求先改派。

### 5.6 入口、作业点与队列点

每个建筑记录：

- `entrance_offset_x/y`：居民进入/离开；
- `workpoint_id`：实际作业；
- `queue_offsets[]`：岗位忙时的安全等待位；
- `input_dock_offset`：搬入原料；
- `output_dock_offset`：搬出产物；
- `occlusion_anchor`：遮挡判断；
- `visual_origin`：贴图脚点；
- `touch_padding`：触控扩展；
- `job_slots`：同时工作的居民数。

首切片一个岗位只允许一名居民在作业点；其他任务按 FIFO 在队列点等待，队列点满则居民不出发。

### 5.7 放置合法性

放置必须逐项通过：

1. 所有占地格在世界边界内；
2. 地形允许；
3. 与现有排他占地不重叠；
4. 入口朝向合法；
5. 入口外邻格可放道路或已有道路；
6. 道路图连通到生活网络根；
7. 不切断关键现有路线；
8. 作业点/队列点不落入阻挡；
9. 视觉前缘不造成无法处理的遮挡；
10. 建造成本原子预检通过。

失败时不扣资源，不创建半个建筑。

### 5.8 寻路

- 导航图节点为可通行道路格中心、建筑入口和作业/装卸连接点。
- 居民从任意非道路当前位置先走向最近已保留的安全连接点，再进入道路图。
- 采用确定性 A* 或等价实现；同代价路径以固定方向/节点 ID 决胜，便于存档与测试。
- 道路/建筑变化时增量更新图；居民日常移动不重建全图。
- 路径失败返回明确原因：`NO_START_LINK`、`NO_TARGET_LINK`、`ROAD_DISCONNECTED`、`WORKPOINT_BLOCKED`。
- 居民不得穿越建筑、水体、未开放地块或其他静态阻挡；动态居民碰撞以让行/局部避让处理，不改变逻辑路径。

### 5.9 遮挡与可读性

- 居民脚点进入建筑后方遮挡带且身体被遮住超过 40% 时，前景遮挡层降到约 55–70% 或显示角色轮廓。
- 建筑底座和入口不能被状态气泡覆盖。
- 路口、入口和装卸位使用轻度材质差或边界形状表达，不依赖文字。
- 50% 画面缩放下仍能辨认道路连续、入口方向和居民当前行为。

## 6. 动物居民完整 UE

### 6.1 建房

1. 玩家进入建造模式。
2. 选择小型住房。
3. 拖动 `2×2` 预览；系统持续显示占地、入口和道路连通。
4. 合法时确认，一次扣除资源并创建施工态。
5. 施工完成后住房进入 `VACANT`，显示一个空住户位。

### 6.2 邀请

1. 世界入口出现一位可邀请动物，或住房空位提供“邀请”入口。
2. 玩家查看短身份：名字、熟悉职业/兴趣、一个可读特征；不显示复杂数值面板。
3. 只有可用住房槽才能确认邀请。
4. 确认后住房槽和动物 ID 原子预留。
5. 动物沿道路到住房；无路时邀请保持保留态，不吞资源。
6. 到达住房门口后完成入住，解锁派遣。

### 6.3 入住与生活

- 居民拥有 `home_building_id`、`home_slot`、当前位置、日程与当前岗位。
- 没有任务时优先在住房/附近生活点活动，而不是站在生产建筑旁永久待命。
- MVP 生活动作：在家、门口停留、短距离散步、前往岗位、返家。
- 生活动作不得抢占已承诺的工作任务；紧急阻塞处理也不需要玩家逐个叫回。

### 6.4 派遣

1. 玩家点建筑，看到岗位空位。
2. 打开可用居民列表；默认按“空闲且可达”排序。
3. 选择一名居民并确认。
4. 系统预检：居民已入住、当前可改派、岗位空闲、住房—岗位有路。
5. 成功后建立长期 `assignment`；居民在工作时段自动领取该岗位任务。
6. 改派不会瞬移；当前安全原子任务完成或取消到安全点后再前往新岗位。

### 6.5 工作与产出

1. 岗位调度器检查日程、输入、输出容量、作业点和路径。
2. 全部可用时，原子预留输入/输出空间和作业点。
3. 居民从当前位置出发。
4. 到达后切换工作姿态，建筑/田地进入工作中。
5. 完成时生成产出到建筑输出位或居民搬运物。
6. 居民把产出搬到存储或已承诺订单的装卸点。
7. 成功存放后任务完成，释放预留并进入下一任务/生活。

### 6.6 阻塞

阻塞只显示第一个可行动原因：

`缺路 > 作业点不可用 > 输出满 > 缺输入 > 无岗位居民 > 日程未到`

玩家可以点阻塞标记定位到断路、仓储、物品来源或岗位，不需要打开多层菜单。

## 7. 动物居民状态与任务系统

### 7.1 身份生命周期

`VISITOR → INVITED_RESERVED → ARRIVING → MOVING_IN → RESIDENT`

MVP 不提供驱逐/永久离开。取消邀请仅在动物尚未开始到达且无资源结算时允许。

### 7.2 日常执行状态

| 状态 | 进入条件 | 行为 | 出口 |
|---|---|---|---|
| `AT_HOME` | 已入住、无紧迫任务 | 居家/门口生活 | `LEISURE` / `ASSIGNED_READY` |
| `LEISURE` | 日程允许、无工作任务 | 安全点短距离活动 | 任务到达/返家 |
| `ASSIGNED_READY` | 有岗位且工作时段到达 | 请求任务 | `RESERVING` |
| `RESERVING` | 调度器选中任务 | 预留输入、输出、作业点 | 成功到 `PATH_REQUESTED`；失败到 `BLOCKED` |
| `PATH_REQUESTED` | 资源预留成功 | 计算确定性路径 | `WALKING` / `BLOCKED` |
| `WALKING` | 路径存在 | 沿道路移动 | `QUEUEING` / `ARRIVED` / `INTERRUPTED` |
| `QUEUEING` | 作业点忙、有队列位 | 在安全点等待 | `ARRIVED` / `BLOCKED` |
| `ARRIVED` | 到达作业点 | 朝向和姿态过渡 | `WORKING` |
| `WORKING` | 作业开始 | 进度推进，建筑同步 | `OUTPUT_READY` / `INTERRUPTED` |
| `OUTPUT_READY` | 作业完成 | 创建货物或输出位 | `CARRYING` / `BLOCKED` |
| `CARRYING` | 有目标存储/装卸点 | 搬运并沿路移动 | `DEPOSITING` / `BLOCKED` |
| `DEPOSITING` | 到达目标 | 原子存放/装载 | `TASK_COMPLETE` / `BLOCKED` |
| `TASK_COMPLETE` | 结算成功 | 释放预留，记录一次任务 | 下一任务/生活/返家 |
| `RETURNING` | 日程结束或无任务 | 返回住房/生活点 | `AT_HOME` |
| `BLOCKED` | 任一步无法继续 | 保持资源与任务快照，显示第一原因 | 条件恢复/改派/取消到安全点 |
| `INTERRUPTED` | 切后台、退出、场景切换 | 保存快照 | 恢复到可继续的最近安全状态 |

### 7.3 任务原子性

- 输入在居民确认接单时预留，在真正开始作业时扣除；取消前可安全释放。
- 输出容量在接单时预留，存放成功后转换为实际占用。
- 每个任务有唯一 `task_instance_id`，保存/重载幂等。
- 一个居民同一时间只执行一个主任务。
- 一个作业点同一时间只属于一个居民。
- 任何失败不得重复扣输入、复制产出或重复奖励。

### 7.4 排队与优先级

- 建筑岗位优先级：`LOW / NORMAL / HIGH`，玩家低频调整。
- 同优先级任务按创建时间和稳定 ID 排序。
- 已开始原子作业不被普通优先级抢占。
- 车辆承诺订单可把目标物品配送提高一级，但不能绕过缺料/容量/路径。
- 队列长度由作业点配置；队列满时居民留在当前位置，不聚集在建筑门口。

### 7.5 动物类型与职业

动物类型不决定智力、道德、社会价值或职业上限。数据分四层：

1. `animal_types`：物种、轮廓、尺寸、可见特征和刻板印象风险；
2. `roles`：农夫、烘焙师、司机、木匠等普通玩家能秒懂的工作；
3. `characters`：名字、训练、经历、兴趣、住房和当前身份；
4. `role_castings`：动物—岗位的对应、映射模式、短理由、工作方法和风险控制。

正式职业至少提供四个动物候选、三个轮廓家族，并同时包含直接契合、直观联想或刻意反差中的至少两种。专业能力来自训练、经验或兴趣。

## 8. 世界内车辆订单

### 8.1 设计目的

车辆让“订单”成为玩家世界里的来客和事件，而不是抽象菜单。玩家只在到达时做一次承诺/谢绝或在阻塞时调整，不逐件点装载。

### 8.2 UE

1. 地图边缘出现车辆即将到达的轻提示。
2. 车辆沿道路进入装卸场，减速并停靠。
3. 货箱或装卸架显示 1–3 种需求物和容量，不展示整页卡片。
4. 玩家点车辆查看简短需求，并选择“承诺”或“谢绝”。
5. 承诺后，符合条件的产出配送优先级提高；居民自动搬运。
6. 每次装载都在世界内显示货物进入货箱。
7. 装满后车辆进入完成状态，短鸣笛并开走。
8. 奖励在车辆越过离场检查点后一次发放；HUD 只做短确认。

### 8.3 状态机

| 状态 | 世界表现 | 允许动作 | 出口 |
|---|---|---|---|
| `OFF_MAP_SCHEDULED` | 地图边缘到达提示 | 无 | 到时进入 |
| `APPROACHING` | 车辆沿入口道路行驶 | 观察 | 到达泊位 |
| `DOCKING` | 减速、对齐装卸场 | 无 | 停靠 |
| `WAITING_DECISION` | 司机/货箱等待 | 承诺/谢绝 | `WAITING_GOODS` / `DEPARTING_EMPTY` |
| `WAITING_GOODS` | 货箱显示缺口 | 定位来源/谢绝 | 货物到达/取消 |
| `LOADING` | 居民与货物进入装卸动作 | 观察 | 继续等待/装满 |
| `READY_TO_DEPART` | 满载、完成灯/旗 | 无 | 短延时 |
| `DEPARTING` | 鸣笛、沿路离开 | 观察 | 离场检查点 |
| `REWARDED` | HUD 奖励确认 | 无 | 冷却 |
| `COOLDOWN` | 装卸位空 | 无 | 安排下一辆 |
| `BLOCKED` | 泊位/道路/装卸点异常 | 定位/修路/清理 | 条件恢复 |

### 8.4 失败与慢节奏

- MVP 不使用硬失败倒计时。
- 玩家可谢绝订单；车辆空驶离开，不扣罚资源，稍后刷新。
- 车辆等待不冻结小镇，也不弹强制模态。
- 道路被删除或泊位占用时，车辆停在入口安全点，不穿越建筑。
- 奖励以 `order_instance_id` 幂等；中断恢复不重复。

## 11. 保存、离线与恢复

### 11.1 建议 schema

新版本需要新的保存 schema，具体编号在工程只读回执后确定。保存：

- 网格占用与道路连接；
- 建筑占地、朝向、施工和岗位；
- 住房槽与居民关系；
- 居民位置、日程、派遣、任务、路径进度与携带物；
- 输入/输出/作业点预留；
- 车辆订单、路线、装载、奖励幂等；
- 仓储、货物与资源事务；
- 相机、语言、reduced-motion 和安全区偏好。

### 11.2 离线推进推荐

- 只推进已创建且路径/输入/输出预留有效的任务；
- 用时间上限控制离线结算，避免长时间瞬间产出；
- 返回时把居民放到最近安全状态：住房、建筑入口、作业点或装卸点；
- 返场只总结一次关键结果，不连续弹窗；
- 车辆若离线完成装载，返回后仍需表现短离场过程再发奖励；
- 不自动创建新任务直到返场结算完成。

### 11.3 中断恢复

- 每个任务与订单使用唯一实例 ID；
- 写入顺序：资源/预留 → 实体状态 → 时间戳 → 提交版本；
- 读取顺序：schema 迁移 → 校验外键 → 恢复占用 → 恢复导航 → 推进有限时间 → 绑定视图；
- 无法恢复的路径任务释放未消耗预留并回到 `BLOCKED`，不丢资源。
