## 复核结论

以下可逆默认值满足已批准的产品方向，可作为代表性运行切片的设计基线：

1. 单一记忆点：动物不是按钮或加成，而是看得见、会走路、会生活并让小镇运转起来的居民。
2. 低频操作：玩家负责建造、邀请、派遣与调整，不逐次点击生产。
3. 空间规则：田地、道路为 `1x1`；住房、代表性工作建筑为 `2x2`；装卸场为 `3x2`。
4. 道路逻辑采用四方向连通，运行时使用 45° 等距表现。
5. 一名居民同一主要工作时段只承担一份主要任务，不提供 RTS 式直接移动。
6. 产出由居民自动搬运；目标满载或断路时在世界内清楚阻塞。
7. 车辆订单无强制倒计时；完成后装载并离场，放弃不惩罚。
8. 主页面以世界内对象和动画表达状态，常驻 UI 仅保留资源、设置和情境操作。
