## 设计取舍

- 保留：coins、renown、共享库存、直接世界对象、分层交付和可见成长。
- 不加入：第三常驻货币、换皮订单栏、强制社交、孤立配方、只涨数值升级。
- 延后：保存/离线结算、具体数值、社交合作、正式美术包；它们不能替代核心循环，也不能在本来源中假定为已实现。
