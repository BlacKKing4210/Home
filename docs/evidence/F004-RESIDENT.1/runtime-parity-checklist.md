## 视觉与交互对齐

- 信息焦点顺序：世界中的动物与车辆 → 当前状态条 → 单一下一步卡片 → 顶部资源与设置。
- 建筑、田地、道路、装卸场都落在正式网格与占地目录，不用自由摆放像素碰运气。
- 角色运动只改变视觉表现，不修改逻辑占地、碰撞、触控区域或道路节点。
- UI 使用 Godot 原生 `Control`、动态文本和运行绘制；没有整屏截图 UI。
- 触控对象按 720 × 1280 设计坐标构建，桌面窗口缩放后仍通过真实点击。
- 原创资产的轮廓、暖色屋顶、青绿色金属、土石材质和左上光向保持一致。
- 成功反馈由车辆离场、装载勾选、彩色粒子、奖励文本和声音共同承担。
- 减弱动态关闭装饰性连续运动，但不删除状态与结果信息。
